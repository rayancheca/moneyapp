## 4. The transfer flow — everything needed to build it

**Design decided.** 2D **"The Spine"**: directed arc diagram on a vertical account spine, accounts
ordered net-source → net-sink, monthly rhythm rail beneath. 3D **"The Tower"**: account pillars on a
ring with **time as the vertical axis**, one arc per (edge, month). SVG + orthographic projection —
**not WebGL** (deterministic, so visual snapshots survive; axe-inspectable; zero bundle).

**Encodings — two channels, because one cannot say both:** stroke width = **dollars**, dash cadence =
**transfer count**. SoFi Savings→SoFi Checking is 299 × ~$327; Chase→SoFi Savings is 23 × ~$3,435 —
near-identical totals, opposite behaviour.

**Net vs Gross must be first-class.** Three edges run both ways; he round-trips money, so gross badly
overstates real movement. In the prototype, gross draws 4 arcs in the return region and **net leaves
exactly 1** — and that one is honest (SoFi Checking → Robinhood Cash is a genuine upstream flow).

### ⚠️ The service must NOT key solely off `transfer_group_id`
Measured on the real DB: **650 transfer groups — 516 properly paired, 134 single-leg.**
**`Chase Sapphire` has 107 groups and 0 edges**, so a naive implementation silently drops
**$33,578.97** of card payments and an entire account.

- **101 of those pairings are recoverable** with high confidence: same-day, exact opposite amount,
  unique match, and the outflow's description names the card (*"Payment to Chase card ending in 9805"*).
  These are **not** the single-sided cases the pass-12 doctrine refuses — both legs exist. It is a
  detector gap.
- **The money math is already safe**: those rows carry a `kind='transfer'` category, so
  `spendingBucket` (which gates on category **kind**, never on `transferGroupId`) excludes them.
  Verified **zero** leak into spending on both databases.

**Recommended order:** (1) build the view *tolerant* — edges from `transfer_group_id` where present,
falling back to `kind='transfer'` + account-side inference — so it is honest immediately with **no DB
write**; (2) fix the detector's 101 pairings as a separate guarded real-DB pass (backup + dry-run +
delta-guards + `source='user'`). Either way **surface the unattributed count** rather than drawing a
partial picture — the prototype does this with a ledger reconciling all 650 groups and a hatched
"GAP"-stamped ghost node for Chase Sapphire.

## 5. How to work on this repo (learned the hard way this session)

### 🔴 `pnpm e2e` can gate against a STALE bundle
`playwright.config.ts` runs `pnpm start`, which serves whatever `.next` exists. **Two waves were
signed off this way**, and the rebuild immediately exposed a client/server boundary violation that had
taken **two pages down** (`countPhrase` exported from a `"use client"` module and *called* by Server
Components). **`tsc` cannot see that class of bug — only a real render can.**

`e2e/global-setup.ts` now has `assertBundleIsFresh()`, which **throws** (never warns) if anything under
`src/` is newer than `.next/BUILD_ID`, naming the file and the drift. Escape hatch `E2E_ALLOW_STALE=1`.
**Always gate with `pnpm e2e:fresh`.**

### The gate sequence
```bash
node_modules/.bin/tsc --noEmit
node_modules/.bin/vitest run --reporter=dot
node_modules/.bin/next build
node_modules/.bin/playwright test --reporter=line
```

### Other traps
- **Never `git add -A`.** `node_modules` and `.env` are symlinks; add explicit paths.
- **Synced `Desktop`** leaves conflict copies (`routes.d 5.ts`) that `tsconfig` globbed in and that
  failed typecheck. Now excluded via `**/* ?.ts` — note TS exclude globs support `?` but **not**
  `[0-9]` character classes (the first attempt parsed fine and did nothing).
- **Visual snapshots:** never bulk-regenerate. Prove each pixel change maps to an intended change,
  then `--update-snapshots=changed`. If a snapshot differs between consecutive captures it is an
  **animation-settling bug**, not a stale baseline — fix it with a Web-Animations `finished` wait
  (precedent in `openHydrated` / `e2e/axe-helpers.ts`).
- **e2e shares ONE database** (`workers: 1`). A spec must **establish** any persisted precondition it
  depends on, not inherit it. A `?view=` param wins for one render but does **not** persist — only the
  control click does.
- **`min-width: auto` on grid/flex children** is the repo's recurring overflow bug. Fix with `min-w-0`.

### The method that worked
Waves of parallel agents with **strictly disjoint file ownership**, plus a gate agent that runs the
full sequence and is explicitly told **never to weaken an assertion**. Zero file conflicts across five
waves. Always RED-verify a regression test by reverting the fix.
